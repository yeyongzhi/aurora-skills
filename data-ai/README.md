# data-ai · 数据与 AI

处理数据、以及用 AI 构建应用的能力。

**收纳**：数据清洗/转换、统计分析、可视化、ETL、爬虫与反爬、LLM 应用开发、RAG、Prompt 工程、模型评测。

**不收纳**：产出 Word/Excel/PPT 文件 → [`office-docs/`](../office-docs)；AI 辅助写代码 → [`development/`](../development)；投资/财报相关的数据分析 → [`finance/`](../finance)。

**举例**：`csv-cleaner`、`chart-from-data`、`web-scraper`、`rag-eval`、`prompt-optimizer`
