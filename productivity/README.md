# productivity · 效率与事务

个人事务与日常流程的自动化。

**收纳**：日程与待办、笔记与知识库、邮件处理、文件与目录整理、表单与填报、个人自动化脚本、快捷键与工作流。

**不收纳**：系统级运维 → [`system/`](../system)；结构化的学习计划 → [`learning/`](../learning)。

**说明**：这是兜底分类，一个 skill 在别处都放不下时放这里，并在 `tags` 里补线索。

**举例**：`inbox-triage`、`daily-standup-digest`、`file-batch-rename`、`todo-sync`
