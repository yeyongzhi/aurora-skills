# finance · 金融与商业

钱、生意与决策分析。

**收纳**：投资研究与行情分析、财报解读、记账与预算、估值建模、商业/咨询分析框架（SWOT、波特五力、MECE 等）、行业研究。

**不收纳**：通用的数据清洗与绘图 → [`data-ai/`](../data-ai)；产出投资报告文档 → [`office-docs/`](../office-docs)。

**规则**：只做信息整理与框架化分析，不给具体买卖建议；涉及金额计算必须标注数据来源与时间。

**举例**：`earnings-decode`、`monthly-budget-review`、`consulting-framework`、`industry-map`
