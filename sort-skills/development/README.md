# development · 软件开发

写代码、读代码、改代码相关的能力。

- `languages/` —— 具体语言：语法速查、惯用法、版本迁移、生态工具链
- `frameworks/` —— 具体框架：项目结构约定、最佳实践、常见报错
- `engineering/` —— 跨语言工程能力：重构、代码审查、测试、调试排错、性能优化、Git 提交规范

**收纳**：产出物是代码或代码相关的分析结论。

**不收纳**：环境搭建与构建流水线 → [`devops/`](../devops)；生成文档/报告 → [`office-docs/`](../office-docs)；用 AI 写代码 prompt → [`data-ai/`](../data-ai)。

**举例**：`refactor-planner`、`typescript-strict-migration`、`flaky-test-hunter`、`code-review-checklist`
