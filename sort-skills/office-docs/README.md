# office-docs · 文档与办公

产出和处理"给人看的东西"。

**收纳**：Word / Excel / PPT / PDF / Markdown 的生成与互转、报告与图表、会议纪要、简历、合同/公文模板、格式规范化。

**不收纳**：数据分析本身 → [`data-ai/`](../data-ai)；图片视频素材处理 → [`media/`](../media)。

**举例**：`markdown-to-docx`、`weekly-report-builder`、`ppt-from-outline`、`pdf-table-extract`、`meeting-notes-formatter`
