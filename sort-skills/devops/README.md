# devops · 工程与运维

让代码跑起来、持续跑下去的能力。

**收纳**：环境搭建、依赖与包管理、构建打包、CI/CD、Docker/K8s、Git 工作流、部署发布、日志监控告警、证书与域名、备份恢复。

**不收纳**：写业务代码 → [`development/`](../development)；Linux/Windows 本机系统维护 → [`system/`](../system)。

**举例**：`env-bootstrap`、`github-actions-debug`、`docker-image-slim`、`release-notes-generator`、`oncall-log-triage`
