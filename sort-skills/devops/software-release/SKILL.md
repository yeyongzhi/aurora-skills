# 软件构建与发布

完成构建打包、版本维护、主分支集成、版本标签和安装包发布，让代码、产物与更新日志对应同一次发布。遵循用户指定的平台、版本和发布范围。

## 识别项目

- 读取仓库指引、Git 状态、远端、版本文件、构建脚本和 CI 工作流，确定产物为 `dist`、安装程序还是两者都有。使用项目既有工具链和锁文件，不猜测打包命令。
- 获取远端分支和标签，从远端默认分支及仓库配置识别主分支（例如 main 或 master）；两者同时存在时不能仅凭名称选择。
- 查找产品介绍站点（例如 VitePress）及已有更新日志，沿用路径、语言、格式和日期约定。没有日志时无需新建站点或日志体系。
- 以最近一次已发布版本到本次发布内容为范围，结合提交和实际差异提炼变更。保留已有改动，不收录无关文件、凭据或生成目录。
- 完整发布请求涵盖必要的提交、推送、主分支合并、标签和 GitHub Release；只要求本地构建、预览或草稿时遵守该限制。仅在版本、目标仓库或范围存在影响结果的歧义时询问。

## 版本与更新日志

1. 采用 SemVer：不兼容变更递增主版本，向后兼容的新功能递增次版本，向后兼容的问题修复递增修订版本。递增主版本后次版本和修订版本归零，递增次版本后修订版本归零。纯构建、文档或维护发布默认递增修订版本；0.x 兼容性策略沿用项目约定。用户指定版本时检查格式、递增关系及冲突。
2. 正式发布标签固定为 `vX.Y.Z`，例如 `v1.4.2`，不得使用 latest 代替。预发布仅在用户要求时按 SemVer 使用后缀，并明确它与正式标签格式不同。
3. 同步项目实际使用的版本源及派生元数据，如包清单、工作区包、桌面应用配置和锁文件。使用既有版本工具，不全局替换所有版本字符串，不升级无关依赖。
4. 产品站点已有更新日志时添加本版本条目，版本与发布日期一致。每次尽量不超过 **5 条**：合并同类变更，描述用户可感知的结果，省略琐碎提交；确有必要超过时说明原因。每条以对应 emoji 开头，严格保持以下映射。

| 标记 | 更新类型 |
| --- | --- |
| ✨️ | 新增功能 |
| 🐛 | 问题修复 |
| 📝 | 文档更新 |
| 🎨 | 样式优化 |
| ♻️ | 代码重构 |
| 🧪 | 性能优化 |
| ⚡️ | 测试更新 |
| 📦️ | 构建更新 |
| 🌐 | 持续集成 |
| 🔧 | 日常维护 |
| ⏪️ | 版本回退 |

Release 说明复用这些精简条目。没有站点日志时从实际差异生成说明，仍使用同一 emoji 规则，不编造功能或修复。

## 集成、构建与发布

1. 提交发布所需的代码、版本元数据和日志，集成到最新主分支。可快进时优先快进，有分叉时遵循仓库合并策略；解决冲突后重新检查，不丢弃任一方代码。受保护分支通过 PR 和必要检查完成合并，权限或审核阻止合并时报告剩余事项，不声称发布完成。
2. 对合并后的最终发布提交运行适当检查、生产构建及打包命令，必要时构建文档站点验证日志。确认 dist 或安装程序真实生成且非空，核对嵌入版本、平台和架构。安装程序进行可行的启动或安装验证，说明未验证的平台；源码压缩包不算安装程序。
3. 产物必须来自最终发布提交。使用 CI 时确保工作流指向该提交并等待结果。标签触发的流水线先通过可在本地或分支执行的检查，再创建标签，等待构建成功后发布。代码或版本变化后重新构建，不上传旧产物。
4. 推送主分支，在最终发布提交上创建带注释的 `vX.Y.Z` 标签并推送该标签。验证远端主分支包含该提交、远端标签指向该提交。同名标签已存在时检查目标与发布状态，不移动、删除或强制覆盖已发布标签；冲突时停止该版本发布并说明原因。
5. **有安装程序时必须发布 GitHub Release 并上传安装资产**，使用对应标签与精简说明；按项目约定提供签名、校验文件和必要平台产物。使用现有 GitHub 连接器、CLI 或工作流，避免重复创建。可先暂存为草稿，全部必需资产成功后正式发布并验证下载链接。只有 dist 时交付构建目录，完成版本和标签流程；是否上传 dist 归档沿用用户或项目约定。
6. 验证主分支、版本、远端标签、Release 资产及日志一致。站点日志源文件随发布代码集成；站点部署沿用已有自动工作流，不额外部署到未经授权的服务。

## 中断与交付

- 检查或构建失败时先修复再发布。缺少签名凭据、GitHub 权限、必要平台环境或主分支审核时，完成可独立执行的工作，明确阻塞项。
- 部分发布成功时保留现场，记录提交、已推送标签、Release 状态和已上传资产。重试先查远端，只补齐缺失步骤；上传失败不得报告成功，不自动删除公开发布或回退主分支。
- 不使用强制推送、破坏性重置或删除用户文件绕过冲突；并发更新后重新集成并验证。不打印或写入令牌、证书及密钥。
- 最终报告版本和标签、主分支及提交、产物绝对路径、验证结果、Release 链接及资产、日志位置与未完成事项。没有安装包时明确产物为 dist；远端发布未完成时明确当前状态。
